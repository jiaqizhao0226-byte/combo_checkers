# 特效本地验收台

这里用于逐项审核新版 3D 战斗特效。候选代码与正式战斗隔离，未经明确确认不会加入 `APPROVED_BATTLE_VFX`，也不会由 `game.js` 引用。

验收镜头固定使用正式游戏的战斗镜头方向，不允许旋转或缩放后换角度验收。

统一入口为 `index.html`。桌面端可点击左侧列表，手机竖屏可使用左上角“选择特效”下拉框；目前可切换 VFX-01、VFX-02、VFX-03 与 COMBO-02 至 COMBO-08，未制作项目保持禁用。

当前候选：

- VFX-01 近战攻击命中：已通过并接入正式游戏。
- VFX-02 伤害数字：已通过并接入正式游戏的普通对敌伤害。
- VFX-03 主角受击反馈：候选 I 已通过并接入正式游戏；上半身绕脚底支点倾倒，双脚与整体高度锁定，尾巴、持剑手与剑均无独立动作。
- 连击奖励不再按“通用递进/统一收束”处理，而是按原版 2 至 8 连的独立玩法逐项验收。
- COMBO-02 追踪飞镖：已通过并接入正式游戏；验收台保留二连跳、索敌、弧线追踪、刀刃切入身体轮廓的命中，以及敌人、道具和无目标回血三种基础场景。
- COMBO-03 稻草人：当前本地候选，包含三连跳、召唤、全场嘲讽、独立友军血条、攻击红线、持续承伤与生命耗尽击毁。
- COMBO-06 时间静止：当前本地候选，包含六连跳、交叉收紧与双臂展开定格、全场十二个罗马数字时标、悬停粒子、普通敌人及 Boss 动作截停、两回合状态刻度与统一解除。
- COMBO-04 六芒冲击波：当前本地候选，包含四连跳、六个棋盘轴向射线、逐格路径高亮、小怪秒杀、Boss 固定 60 伤害和轴线外目标不受影响。
- COMBO-05 生命虹吸：当前本地候选，包含五连跳、淡绿色全场生命流向、普通敌人当前生命 20%（最低 5）、Boss 固定 30、缺失生命治疗、溢出护盾与 60 点护盾上限三种场景；溢出后持续显示贴身能量护盾和企鹅头顶的当前护盾总值。
- COMBO-07 流星火雨：当前本地候选，包含七连跳、收身蓄力与举剑召唤前摇、十二颗带岩芯和双层火尾的小型流星在极短窗口内高速坠落、每个敌人仅一次的全场伤害结算、小型落点爆炸与连续短震；不附加燃烧或其他状态。
- COMBO-08 绝对反射：当前本地候选，包含八连跳、空闲鳍肢向左前撑开且持剑手向右外展的专属防御动作、金色镜面护罩组装、单批低开销金色闪光粒子、连续四个完整敌方回合内全部攻击归零、攻击转为金色并原路折返、对攻击者造成等额伤害；粒子在受击接触时增亮外扩，第四个敌方回合全部结算后再随护罩散开消失，敌人始终正常行动，因此与六连时间静止不重复。

连击奖励验收顺序：2 连追踪飞镖 → 3 连稻草人 → 4 连六芒冲击波 → 5 连生命虹吸 → 6 连时间静止 → 7 连流星火雨 → 8 连绝对反射 → 9 连传奇技能。每项通过后才接入正式战斗。
