# 第一章小怪模型验收台

这是与正式小游戏运行流程分离的本地 Three.js 验收页面。页面不会修改关卡数据、战斗事件或正式特效白名单，但已批准的程序化模型源会与正式小游戏共用，保证验收页和局内表现不会分叉。

`SlimeCandidate.js` 与 `EnemyCandidates.js` 中的第一章八类小怪已通过本轮验收，并接入 `src/game/Units.js` 的正式敌人工厂。后续精修仍先在本页验收，得到确认后再同步影响正式游戏。

在 `prototype-threejs` 目录启动任意静态文件服务器，然后访问：

```text
/model-review/
```

验收顺序建议：正面物种辨识、侧面轮廓、棋盘实际占比、材质层次。页面中的移动/攻击/受击只用于观察轮廓，不代表最终动画。
