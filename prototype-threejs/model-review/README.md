# 第一章小怪模型验收台

这是与正式小游戏分离的本地 Three.js 页面。已进入精修流程的小怪会优先读取当前候选模型，其余小怪仍读取 `src/game/Units.js`；页面不会修改关卡数据、战斗事件或正式特效白名单。

当前候选模型：`SlimeCandidate.js` 与 `EnemyCandidates.js`。第一章八类小怪均已进入独立验收流程，只有通过验收后才会同步进正式游戏。

在 `prototype-threejs` 目录启动任意静态文件服务器，然后访问：

```text
/model-review/
```

验收顺序建议：正面物种辨识、侧面轮廓、棋盘实际占比、材质层次。页面中的移动/攻击/受击只用于观察轮廓，不代表最终动画。
