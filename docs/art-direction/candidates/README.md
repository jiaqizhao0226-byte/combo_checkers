# v2 核心关卡画风候选

三张候选使用同一套玩法结构：竖屏、61 格六角棋盘、企鹅英雄、3 个史莱姆、2 个骷髅、三节点跳跃路线和相同 HUD。现有实机截图只用于约束玩法布局，没有作为画风母版。

## A：精致低细节 2D 卡通

文件：`a-refined-2d-cartoon.png`

- 优势：战斗信息最清楚；角色、棋盘与 UI 的制作和迭代成本最低。
- 代价：氛围感较克制，需要依靠章节色板、地形和 Boss 轮廓增强世界感。
- 适合：把核心操作和长线内容迭代放在首位。

## B：3D 渲染转 2D 商业卡通

文件：`b-rendered-3d-cartoon.png`

- 优势：商业完成度、触感与商店素材表现最好，棋盘与单位有明确体积。
- 代价：角色、敌人和 Boss 的建模/渲染成本最高，批量一致性需要固定管线。
- 适合：希望整体更接近成熟商业休闲游戏，并愿意投入较高资产成本。

## C：统一像素复古

文件：`c-unified-pixel-retro.png`

- 优势：继承当前版本最明确的设计资产，辨识度高；只要严格共用像素网格，整体一致性可以显著提升。
- 代价：受众更偏核心玩家；中文点阵字、章节插画和高阶特效都必须遵守像素规范，否则会再次出现混搭感。
- 适合：保留当前产品记忆，同时以较可控成本完成系统性换皮。

## 共同硬约束

- 竖屏 480 设计短边。
- 核心战斗屏不显示底部导航或商业入口。
- HUD 只保留生命、章节/回合、金币、设置、退出和当前目标。
- 敌我、可移动格、跳跃路线、选中格必须能在一眼内区分。
- 正式资产写入 `assets/v2/`，不覆盖当前发布资产。
