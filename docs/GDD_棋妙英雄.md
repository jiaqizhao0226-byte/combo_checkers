## 1. 游戏概述

### 1.1 核心定位

- **游戏名称**: 棋妙英雄 Combo Checkers
- **类型**: 六角棋盘跳棋 + Roguelite
- **核心循环**: 在六角棋盘上通过跳跃消灭敌人，连续跳跃触发Combo奖励，每关结束选择技能升级
- **Meta循环**: 闯关获得金币 → 升级天赋/抽取装备 → 提升基础属性 → 挑战更高章节

### 1.2 核心体验

玩家在六角棋盘上操控英雄，通过规划跳跃路径消灭敌人。连续跳跃形成Combo链，触发从"追踪飞镖"到"末日炸弹"的6阶强力奖励。每关结束可选择Roguelite技能升级，技能之间可组合出合成技。

### 1.3 游戏结构

```
主菜单 (天赋/装备/商店/冒险)
  ↓ 点击"出发冒险"
章节选择 (4章, 每章10关)
  ↓
战斗关卡 (回合制跳棋)
  ↓ 通关
技能选择 (3选1升级)
  ↓
下一关... (第10关为Boss)
  ↓ Boss通关
章节完成 (+80金币奖励, 技能重置)
  ↓
下一章节 (新敌人、新机制)
```

## 3. 六角棋盘系统

### 3.1 棋盘参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 列数 (COLS) | 9 | 棋盘宽度 |
| 行数 (ROWS) | 9 | 棋盘高度 |
| 半径 (RADIUS) | 4 | 中心到边缘的六角距离 |
| 中心坐标 | (5, 5) | 1-based索引 |
| 有效格子数 | 61 | 正六角形区域 |
| 坐标系 | Pointy-top, Odd-r Offset | 1-based索引 |

### 3.2 坐标系统

使用两套坐标:
- **Offset坐标** (col, row): 用于显示和存储, 1-based
- **Cube坐标** (q, r, s): 用于距离计算和方向扫描, 满足 q+r+s=0

**转换公式**:
```
OffsetToCube(col, row):
  col0 = col - 1  (转0-based)
  row0 = row - 1
  q = col0 - (row0 - (row0 & 1)) / 2
  r = row0
  s = -q - r
  return (q, r, s)
```

**六角距离**:
```
CubeDistance(c1,r1, c2,r2):
  将两点转为Cube坐标
  return max(|dq|, |dr|, |ds|)
```

### 3.3 像素坐标转换

```
HexToPixel(col, row, hexSize):
  w = sqrt(3) * hexSize
  x = (col - 1) * w + (row为奇数行时偏移 w/2)
  y = (row - 1) * hexSize * 1.5
```

### 3.4 六方向定义

Cube坐标系下的6个方向向量:
```
CUBE_DIRS = {
  { 1, -1,  0},  -- 右上
  { 1,  0, -1},  -- 右
  { 0,  1, -1},  -- 右下
  {-1,  1,  0},  -- 左下
  {-1,  0,  1},  -- 左
  { 0, -1,  1},  -- 左上
}
```

### 3.5 棋盘状态数据

```lua
board = {
    pieces = {},        -- 敌人/友方单位列表
    obstacles = {},     -- 障碍物 (岩石、触手)
    items = {},         -- 道具 (血瓶、金币袋、护盾)
    poisonTiles = {},   -- 毒/岩浆DOT地形
    wards = {},         -- 结界/屏障地形
    frostTiles = {},    -- 冰霜地形 (霜降技能)
    altars = {},        -- 祭坛 (第二章)
    crabs = {},         -- 可救援的寄居蟹 (第三章)
    shells = {},        -- 蟹壳目标 (第三章)
}
```

### 3.6 六芒星模式 (第四章)

通过 `SetupHexagram(N)` 激活, N=臂长:
- 总格子数 = `6N^2 + 6N + 1` (N=4时为121格)
- 6条臂从中心延伸, 每条臂宽3格
- ROWS重新计算为 `4N + 1`

## 4. 英雄与移动系统

### 4.1 英雄基础属性

| 属性 | 基础值 |
|------|--------|
| HP | 110 |
| Max HP | 110 |
| ATK | 20 |
| DEF | 2 |

实际值 = 基础值 + 天赋加成 + 装备加成 + 套装加成

### 4.2 移动规则 (FindValidMoves)

- 英雄可移动到**相邻的未被占据的格子** (最多6个方向)
- 以下类型的格子会阻挡移动: 敌人、障碍物、寄居蟹、蟹壳
- 移动**不消耗回合** (移动后仍为玩家行动阶段, 但不能连续移动, 移动后进入敌人回合)

### 4.3 跳跃规则 (FindValidJumps)

跳跃是核心战斗方式:

1. 从英雄位置沿6个Cube方向扫描
2. 找到该方向上**第一个敌人或障碍物** (距离为N)
3. 计算**对称落点**: `落点Cube = 2 × 目标Cube - 英雄Cube`
4. 落点必须是**有效的、未被占据的格子**
5. **多格跳**: 目标不一定在相邻格, 可以在距离N处, 英雄会跳过目标落在N格之后

**跳跃约束**:
- 障碍物跳跃 (isRockJump=true): 跳过障碍物, 障碍物**不被摧毁**
- 寄居蟹和蟹壳会**阻断扫描方向**
- 迷雾区域**阻断视野** (不能看到/跳过迷雾后的单位)
- 远距跳跃时, 目标与落点之间的**所有中间格子**必须无障碍

### 4.4 跳跃伤害

每次跳过敌人时:
- 对被跳过的敌人造成伤害 (详见第6章伤害计算)
- 如果敌人被消灭, 击杀计数+1, 获得金币奖励
- 如果还有可跳跃的目标, 可以继续跳跃 (形成Combo链)

### 4.5 着陆冲击 (无震地落技能时)

```
落地伤害 = max(5, floor(英雄ATK × 0.4))
对落点所有相邻敌人造成该伤害 (减去敌人DEF)
```

## 6. 伤害计算

### 6.1 英雄跳跃攻击伤害 (完整流水线)

```
1. baseDmg = hero.atk + bountyAtkBonus + comboAtkBonus

2. 血怒加成 (HP低于阈值时):
   - Lv1-4: baseDmg *= (1 + (20 + rageLv×6)/100)
   - Lv5: baseDmg *= 2

3. 真实伤害加算:
   - 吸血跳Lv5 (HP>80%): +floor(hero.atk × 0.2)
   - 赏金猎人Lv5: +min(floor(gold/10), 20)

4. 重力践踏 (combo >= 3时):
   baseDmg = floor(baseDmg × (1 + (50 + gravLv×30)/100))

5. Combo乘算:
   comboRate = 0.5 (默认) 或 0.75 (重力践踏Lv4)
   multiplier = 1.0 + (combo - 1) × comboRate
   multiplier上限 = 无 (默认) 或 3.0 (重力践踏Lv4)
   damage = floor(baseDmg × multiplier) + trueDmg

6. 条件乘算 (乘法叠加):
   - 猎手印记: damage += floor(damage × (20+markLv×7)/100)
   - 地刺陷阱Lv5: damage = floor(damage × 1.2)
   - 收集者: 若敌人HP% < 阈值, damage += floor(damage × bonusPct)
   - 祭坛减伤: damage -= floor(damage × altarDamageReduction)

7. Boss护盾: 先消耗护盾, 溢出伤害打HP
```

### 6.2 敌人攻击伤害

```
actualDmg = max(1, enemy.atk - target.def)
```

修正:
- 护盾道具: actualDmg = floor(actualDmg / 2), 消耗护盾
- 吸收护盾 (drainShield): 先消耗, 溢出打HP
- 连击护盾 (_shield): 先消耗

### 6.3 荆棘反伤

```
thornRate = (20 + thornsLv × 8) / 100
thornsDmg = floor(enemy.atk × thornRate)
```

## 7. 连击(Combo)系统

### 7.1 Combo计数

- 每次跳跃击杀敌人后, 如果还能继续跳跃并选择跳跃, combo+1
- combo从0开始, 第一次跳跃后combo=1, 第二次=2, 以此类推
- combo >= 2 时触发对应阶的连击奖励
- combo在敌人回合结束时重置为0

### 7.2 连击冲击波 (被动)

- 条件: combo >= 3 且发生击杀
- 效果: 对棋盘上**所有存活敌人**造成10点固定伤害
- 可以连锁击杀低血量敌人

### 7.3 Combo ATK加成

- `comboAtkBonus`: 通过吸血跳Lv3等技能在combo击杀时获得的临时ATK加成
- 每回合重置

### 8.1 稻草人详细机制

## 24. 胜负判定

### 24.1 胜利条件

- **普通关**: 击杀数 >= 击杀目标
- **Boss关**: Boss HP <= 0
- **第3章附加**: 还需救援目标达标 (rescueCount >= rescueTarget)

### 24.2 "同归于尽"规则

如果英雄在完成胜利条件的同一帧HP降至0:
- **判定为胜利**, 英雄HP设为1

### 24.3 失败条件

英雄HP <= 0, 除非:
1. **黎明使者**未使用: 恢复至30% maxHP (每次冒险1次)
2. **血怒Lv5**死亡免疫: 免疫一次致死伤害 (与黎明使者独立)

### 24.4 失败后

- 显示失败弹窗 (战绩摘要)
- 可选"再来一局" (回到当前章第1关) 或 "返回主菜单"
- 冒险期间获得的金币**保留**
