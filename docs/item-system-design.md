# 道具系统改版策划案 v2.0

> 状态：待确认 | 作者：AI 助手 | 日期：2026-04-23

---

## 1. 现状分析

### 1.1 当前道具（4种）

| 道具 | 图标 | 效果 | 问题 |
|------|------|------|------|
| 血瓶 | ❤️‍🩹 | 回复25HP | 功能明确，保留 |
| 攻击卷轴 | 📜 | ATK+5 永久 | 与技能系统重叠（吸血跳Lv5也给ATK），数值设计简单粗暴 |
| 金币袋 | 💰 | +20金币 | 功能单一，缺少策略性 |
| 护盾 | 🛡️ | 下次受击减半 | 功能明确，但缺少视觉反馈 |

### 1.2 核心问题

1. **缺少策略性**：所有道具都是"踩到即生效"的被动拾取，玩家不需要做决策
2. **与技能系统脱节**：道具和12个技能之间没有协同互动
3. **种类太少**：4种道具对3章30关来说太单调
4. **缺少章节特色**：每章没有专属道具

---

## 2. 设计目标

1. **增加策略深度**：让玩家在"走过去拾取"和"跳跃连击"之间做选择
2. **与技能联动**：道具效果受已拥有技能影响（如磁铁石+赏金猎人）
3. **章节差异化**：每章引入1-2个特色道具
4. **保持简洁**：拾取即生效，不做背包/使用系统，保持轻量

---

## 3. 改版方案

### 3.1 保留道具（2种）

| 道具 | 图标 | 效果 | 调整 |
|------|------|------|------|
| **血瓶** | ❤️‍🩹 | 回复HP | 回复量改为 `max(25, maxHP×15%)`，后期不鸡肋 |
| **护盾** | 🛡️ | 下次受击伤害减半 | 增加视觉：拾取后角色外圈蓝色光环 |

### 3.2 移除道具（2种）

| 道具 | 原因 | 替代 |
|------|------|------|
| **攻击卷轴** | 与吸血跳Lv5/血怒重叠，纯数值堆叠缺乏趣味 | 被"力量果实"替代 |
| **金币袋** | 纯经济道具无策略性 | 被"宝箱"替代 |

### 3.3 新增通用道具（3种，全章可见）

#### 力量果实
| 属性 | 值 |
|------|-----|
| 图标 | 🍎 |
| 名称 | 力量果实 |
| 效果 | 下3次跳跃攻击伤害 +50% |
| 技能联动 | 重力践踏：额外+25%（总+75%）；吸血跳：击杀回复量翻倍 |
| 设计意图 | 替代攻击卷轴，但有限次数，鼓励拿到后积极进攻 |
| 视觉 | 拾取后角色脚下出现3个红色菱形标记，每次跳跃消耗1个 |

#### 宝箱
| 属性 | 值 |
|------|-----|
| 图标 | 📦 |
| 名称 | 宝箱 |
| 效果 | 随机给予：30金 / 50金 / 血瓶 / 力量果实 / 2×护盾 |
| 技能联动 | 赏金猎人Lv3+：金币奖励翻倍；赏金猎人Lv5：必出金币且×3 |
| 设计意图 | 替代金币袋，随机性增加惊喜感，和赏金猎人强联动 |
| 视觉 | 开箱动画：弹出物品图标 + 金色粒子 |

#### 磁铁石
| 属性 | 值 |
|------|-----|
| 图标 | 🧲 |
| 名称 | 磁铁石 |
| 效果 | 拾取后，将周围2圈内的所有道具吸引到相邻格（不吸引敌人） |
| 技能联动 | 六芒结界：同时引爆范围内所有结界 |
| 设计意图 | 策略道具——先规划路线收集磁铁石，再一次吸取大量道具 |
| 视觉 | 蓝色脉冲波纹，道具滑动到新位置 |

### 3.4 章节特色道具（每章独有）

#### 第一章 · 幽暗森林

| 道具 | 图标 | 效果 | 出现条件 |
|------|------|------|---------|
| **蘑菇** | 🍄 | 随机效果：回复20HP / ATK+3持续5回合 / 中毒（-5HP×3回合） | 第1章全关卡 |

- **设计意图**：新手章节引入风险/收益概念，蘑菇可能有毒
- **技能联动**：幽灵步Lv3+免疫毒蘑菇（毒性转化为加速1回合）
- **视觉**：拾取时短暂"？"浮出，然后显示实际效果

#### 第二章 · 深渊海沟

| 道具 | 图标 | 效果 | 出现条件 |
|------|------|------|---------|
| **海星** | ⭐ | 下次连跳长度+2（额外2步不需要相邻目标） | 第2章全关卡 |
| **珍珠** | 🫧 | 存储当前连击数，下回合首跳继承该连击数 | 第2章第5关起 |

- **海星设计意图**：第二章核心是连击奖励，海星直接强化连跳能力
- **珍珠设计意图**：解决"好不容易打出高连击，下回合从0开始"的挫败感
- **技能联动**：
  - 蓄势待发Lv3+：海星额外+1步（总+3）
  - 赏金猎人Lv2+：珍珠额外保留金币加成

#### 第三章 · 烈焰山脉

| 道具 | 图标 | 效果 | 出现条件 |
|------|------|------|---------|
| **火把** | 🔦 | 揭示周围3圈迷雾，持续5回合（离开揭示区域后雾不回来） | 第3章全关卡 |
| **陷阱** | ⚠️ | 拾取后在当前位置放置陷阱，下个踏入的敌人受30伤+眩晕1回合 | 第3章第4关起 |

- **火把设计意图**：第三章有战争迷雾，火把是关键生存道具
- **陷阱设计意图**：在迷雾中布置陷阱，伏击暗影伏击者
- **技能联动**：
  - 六芒结界：陷阱和结界共振，被触发时同时引爆相邻结界
  - 荆棘护甲Lv3+：陷阱触发时额外反弹30%伤害给所有相邻敌人
  - 霜降：陷阱触发时附加2回合冰冻

## 4. 道具生成规则

### 4.1 刷新频率

| 场景 | 当前 | 改版后 |
|------|------|--------|
| 关卡开始 | 随机2个 | 保底1血瓶 + 随机1-2个 |
| 每回合补充 | 不足2个时补 | 不足3个时补 |
| Boss关 | 额外1血瓶 + 3个 | 额外1血瓶 + 1护盾 + 2-3个 |

### 4.2 权重表

| 道具 | 基础权重 | 说明 |
|------|---------|------|
| 血瓶 | 25 | 基础生存 |
| 护盾 | 15 | 防御 |
| 力量果实 | 20 | 进攻 |
| 宝箱 | 15 | 惊喜 |
| 磁铁石 | 10 | 策略（稀有） |
| 章节道具 | 15（总） | 章节特色 |

### 4.3 智能生成

- **低血量保护**：HP < 30%时，血瓶权重×2
- **道具去重**：同一回合不刷出2个相同道具
- **位置分散**：新道具不与已有道具相邻

## 6. 实现优先级

### P0 — 基础改版（最小可行改动）
1. 移除攻击卷轴和金币袋
2. 新增力量果实（限次数增伤）
3. 新增宝箱（随机奖励）
4. 调整血瓶回复公式
5. 调整 TrySpawnItems 权重逻辑

### P1 — 策略道具
6. 新增磁铁石
7. 智能生成（低血量保护、去重、分散）

### P2 — 章节特色
8. 第一章蘑菇
9. 第二章海星 + 珍珠
10. 第三章火把 + 陷阱

### P3 — 技能联动
11. 各技能与道具的联动效果

---

## 7. 不做的事情

- **不做背包系统**：道具踩到即生效，不存储不选择
- **不做道具商店**：金币用于技能升级，不用于购买道具
- **不做道具升级**：道具不分等级，保持简洁
- **不做主动使用**：所有道具被动触发，不增加操作复杂度

---

## 8. 风险与备选

| 风险 | 影响 | 应对 |
|------|------|------|
| 磁铁石太强（一次收割大量道具） | 经济崩溃 | 限制磁铁石出现频率（每关最多1个），或吸引范围缩为1圈 |
| 蘑菇随机性导致挫败感 | 新手体验差 | 第1-3关蘑菇必定是正面效果，第4关起引入毒蘑菇 |
| 珍珠太强（永久保持高连击） | 第二章难度崩溃 | 珍珠保留的连击数上限3，且只保留1回合 |
| 章节道具增加学习成本 | 玩家困惑 | 首次出现时弹出简短说明浮窗（1.5秒） |
