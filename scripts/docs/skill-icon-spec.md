# 技能图标生成规范

> 新增技能时，按此规范生成图标，确保全局风格统一。

---

## 基本参数

| 参数 | 值 |
|------|-----|
| 尺寸 | `64x64` |
| 比例 | `1:1` |
| 透明背景 | `true` |
| 像素风格 | 16×16 像素美术（放大到 64×64） |
| 描边 | 粗黑描边 |
| 边框 | 无框 |
| 背景 | 无背景（透明） |

---

## Prompt 模板

```
极简像素技能图标，[色调][核心意象描述]，16x16像素美术，极少细节，粗黑描边，无框无背景
```

### 参数说明

- **色调**：1-2个颜色词，定义图标主色（如"红色"、"蓝金色"、"暗紫色"）
- **核心意象**：简短描述技能的视觉核心，不超过10个字

---

## 参考图

**必须使用已有图标作为 reference_images**，确保批次间风格一致。

推荐参考图（按优先级）：
1. `assets/image/skill_thorns_20260601034124.png` — 荆棘护甲（绿色，标准风格）
2. 同批次中任一已通过的图标

```json
"reference_images": ["assets/image/skill_thorns_20260601034124.png"]
```

## 配色指南

根据技能类型选择主色调：

| 技能类型 | 推荐色调 | 示例 |
|---------|---------|------|
| 物理/攻击 | 红色、橙色 | 血怒（红色愤怒拳头） |
| 防御/护盾 | 蓝色、蓝金色 | 连击护盾（蓝金色能量护盾） |
| 移动/跳跃 | 绿色、青色 | 踏步打击（绿色靴子冲击波） |
| 雷电/能量 | 黄色、黄紫色 | 闪电链（黄色闪电链式连击） |
| 暗系/吸血 | 暗紫色、鲜红+白色 | 吸血跳（红色爱心被白色獠牙咬住） |
| 地面/陷阱 | 棕色、灰色 | 地震着陆（棕色大地震裂） |
| 光明/神圣 | 金黄色 | 黎明先驱（金黄色曙光太阳） |
| 收割/终结 | 紫色 | 收集者（紫色镰刀收割） |
| 射击/远程 | 蓝色、青色 | 分裂射击（蓝色箭矢三向分裂） |
| 组合技能 | 双色混合 | 雷震天罚（黄紫色）、血棘共生（红绿色） |

---

## 对比度要求

**图标必须在深色背景上清晰可辨**（游戏 UI 背景为深蓝/深紫/深红）。

- 避免纯暗色图标（如纯深红、纯深紫）
- 使用亮色元素确保辨识度（白色高光、亮色主体）
- 暗色系技能需要加入亮色对比元素（如吸血跳用白色獠牙+鲜红爱心）

---

## 生成工具调用示例

```json
{
  "prompt": "极简像素技能图标，蓝金色能量护盾发光，16x16像素美术，极少细节，粗黑描边，无框无背景",
  "name": "skill_combo_shield",
  "target_size": "64x64",
  "transparent": true,
  "reference_images": ["assets/image/skill_thorns_20260601034124.png"]
}
```

---

## 文件命名与存放

- 路径：`assets/image/skill_{技能id}_{时间戳}.png`
- 注册：在 `scripts/IconAtlas.lua` 的 `PATHS` 表中添加条目
- 格式：`skill_{id} = "image/skill_{id}_{timestamp}.png"`

---

## 审核流程

1. 生成图标后展示给用户确认
2. 重点检查：
   - 风格是否与现有图标统一（像素感、描边粗细）
   - 在深色背景上是否清晰可辨
   - 意象是否准确表达技能含义
3. 不通过则调整 prompt 重新生成
4. 通过后更新 `IconAtlas.lua` 并构建
